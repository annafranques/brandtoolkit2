# Figma Brand Assets File Setup Guide

This guide will help you create a Figma file to organize your fonts, colors, and logos for the Brand Toolkit.

## Recommended File Structure

### 1. Create a New Figma File
- Open Figma and create a new file
- Name it something like "Brand Assets" or "[Your Brand Name] Brand Guidelines"

### 2. Create Pages/Frames for Organization

#### Page 1: **Typography**
Create frames for:
- **Primary Font**: Display samples of your primary typeface
  - Different weights (Light, Regular, Bold)
  - Different sizes (Display, Heading, Body, Caption)
  - Example: "Aa Bb Cc Dd... 0123456789"
  
- **Secondary Font**: Display samples of your secondary typeface
  - Different weights and sizes
  - Character set examples

- **Typography Styles**: Create Text Styles in Figma for:
  - Display (largest headings)
  - Heading (section titles)
  - Body (paragraph text)
  - Button text
  - Caption text

#### Page 2: **Colors**
Create color swatches for:
- **Primary Colors**: Your main brand colors
- **Secondary Colors**: Supporting colors
- **Accent Colors**: Highlight/CTA colors
- **Neutral Colors**: Grays, blacks, whites

For each color:
- Display the hex code (e.g., #000000)
- Show the color swatch
- Add a label/name (e.g., "Primary Black")
- Optionally show usage examples

**Tip**: Use Figma's Color Styles feature to create reusable color variables.

#### Page 3: **Logos**
Organize logo variations:
- **Primary Logo**: Main logo (black, white, color versions)
- **Complementary Logos**: Alternative logo variations
- **Logo Lockups**: Logo with tagline or company name combinations
- **Logo Usage Examples**: 
  - Clear space guidelines
  - Minimum size examples
  - Do's and Don'ts
  - Background variations (light/dark)

For each logo:
- Export at different sizes (include download options)
- Show on different backgrounds (light, dark, colored)
- Include spacing guidelines

#### Page 4: **Assets Library** (Optional)
- Icons
- Patterns
- Illustrations
- Photography style guidelines

## Quick Setup Steps in Figma

### Setting Up Color Styles:
1. Create rectangles for each color
2. Select the rectangle
3. In the right panel, click the color fill
4. Click the "Style" icon (4 dots)
5. Click "+" to create a new style
6. Name it (e.g., "Primary Black" or "Brand Primary")
7. Repeat for all colors

### Setting Up Text Styles:
1. Create a text layer with your font
2. Select the text
3. In the right panel, click the text style dropdown
4. Click "+" to create a new style
5. Name it (e.g., "Heading 1" or "Body Text")
6. Repeat for all typography variations

### Organizing Logos:
1. Place each logo variation as an image
2. Use frames to group related logos
3. Add text labels above each logo
4. Export settings: Right-click frame → "Export" → Set formats (PNG, SVG, etc.)

## Linking to Your Brand Toolkit

Once you've created your Figma file:
1. Get the file key from the Figma URL (the part after `/file/` and before the file name)
2. Use the file key in your Brand Toolkit's Figma sync feature
3. The toolkit can import colors and typography from your Figma file

### Example Figma URL:
```
https://www.figma.com/file/ABC123xyz/Brand-Assets
                              ^^^^^^^^
                           File Key (ABC123xyz)
```

## Best Practices

1. **Consistency**: Use Figma Styles (Color Styles and Text Styles) so changes update everywhere
2. **Documentation**: Add notes/labels explaining when to use each asset
3. **Export Settings**: Pre-configure export settings for logos (different sizes/formats)
4. **Organization**: Use frames and auto-layout to keep things tidy
5. **Naming**: Use clear, consistent naming (e.g., "Logo_Black", "Logo_White", "Primary_Color")

## Recommended Frame Sizes

- **Color Swatches**: 100x100px or 200x200px
- **Logo Frames**: 400x400px (with clear space guides)
- **Typography Samples**: 800px width (to show full character sets)

---

**Note**: The Brand Toolkit's Figma sync feature can automatically import colors and typography from your Figma file, so setting up Color Styles and Text Styles in Figma will make syncing easier.
